# Fonts

Self-hosted so the site needs no third-party font host (the CSP allows
`font-src 'self'` only). Chosen by the owner on 23 Nov 2026 (option A).

| File | Family | Weights | Subset |
|---|---|---|---|
| `manrope-v23-*.woff2` | Manrope (v23) | variable 200–800 | latin, latin-ext, greek |
| `sofia-sans-xc-700-v6-*.woff2` | Sofia Sans Extra Condensed (v6) | 700 | latin, latin-ext, greek |

Both are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Source: Google Fonts. File names carry the
font version: a new version gets new names (they are cached as immutable).
